# Login Feature

## Purpose

Allow a registered user to sign in to the ABC Bank application.

## Login form

The form should include:

- Email address
- Password
- A **Sign in** button

## Expected behavior

- If the user enters valid details, show a successful sign-in message.
- If the details are incorrect, show a helpful error message.
- Do not display or store the password as plain text.
